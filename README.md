# CSM-AD

Alzheimer’s disease (AD) patient data are critical for providing better patient
care. However, the lack of uniform methods or different measurement scales
across hospitals, electronic health records (EHRs), and real-world datasets
hinder data interoperability and cross-border medical studies.
We propose the Common Semantic Data Model for Alzheimer’s (CSDM-AZ)
— an ontology (Knowledge Graph schema) to unify representations of Alzheimer’s disease
patients’ relevant concepts to enable interoperability, facilitate automated cross-11
dataset queries, and support continuity of care.
